# Conttributing to SchildiChat Revenge

Contributions may be accepted as follows:
- Translations via [Weblate](https://weblate.spiritcroc.de/projects/schildichat/schildi-revenge/)
- Pull Requests via [GitHub](https://github.com/SchildiChat/schildi-revenge/pulls)

Please write PRs and issue descriptions yourself, to prove you know what you're talking about and there's a human
involved. If you really want to provide further insights using LLM output, clearly label it as such and put it in a
quote block.

I aim for Revenge to be very intentional and prefer a slow "do it once, right" development cycle over fast development.
This somewhat goes against recent rapid AI development practices, but I hope it will ensure a better quality application
in the long run.

- If your changes look prevailingly AI-generated, I may not even bother to review them, especially if I suspect that
  reviewing them would cost more time than generating an equivalent patch myself.
- I'm very biased towards how core functionality should look, and want to be very intentional implementing those. I.e.,
  chances to accept big features are low, especially if we did not chat about it before and I gave you green light.
- It helps a lot if contributions are small and targetted at a specific problem rather than solving multiple.
  Generally try to go for the minimal and most elegant approach to solve a problem.
- Always keep in mind we want to support both Android (touch-based) and Desktop (keyboard and mouse based) as targets,
  and every core functionality should work both with only pointer input or only keyboard input, where it makes sense.
- If you use any LLMs / AI, you're still expected to understand and stand by every single line of code yourself. Please disclose
  in your PR description which AI models you used and to what degree.

Of course I love to see if people care about this project and are willing to contribute! Just keep in mind that I
care a lot about this hobby project for my own use, so I hope you can understand this project is governed in a [Benevolent
Dictator for life](https://en.wikipedia.org/wiki/Benevolent_dictator_for_life) fashion. Of course you're always free to
fork while maintaining the [license terms](LICENSE) :)
